# 0.10 原厂背屏滤镜验证

日期：2026-10-17。环境：小米 17 Pro Max / popsicle，HyperOS OS4.0.2.0.XPBCNXM，Leica camera 0.219 / build219 KernelSU 模块，相机 6.6.000570.5。

## 原厂参考与最终实现

临时停用移植模块和 LSPosed，在系统原厂相机 6.7.000280.0 实测效果面板，然后恢复模块、相机设置、原作用域和身份配置。

背屏效果使用 6.6 APK 内置的原厂视图工厂 p9.v、数据与入口工厂 j2.c，以及 p9.t 的原厂图标和分组。原生控制器负责魔棒入口、滤镜／美颜标签、点击选择、滚动吸附、应用与关闭。补丁只对选中框及活动图标着徕卡红色，不设置滤镜点击监听器或提交回调。

删除旧版对滤镜列表、缩略图尺寸、行距、圆角、文字位置与选中框位置的改写。主屏继续走徕卡分支。没有重新分发系统相机、OTA、厂商库或解包资源。

## 实机结果

| 操作 | 结果 |
| --- | --- |
| 外层效果入口 | 原厂魔棒图标 |
| 进入面板 | 滤镜／美颜两个原厂标签均存在，可切换 |
| 点选奶油 | 原生滤镜 ID 131164，关闭再打开保持 |
| 滑动选择清新 | 原生滤镜 ID 131167，关闭再打开保持 |
| 列表往返 | 可滑到生动 8239，并反向回到原图 66048 |
| 底部原图按钮 | 可恢复原图；测试后已恢复原图 |
| 关闭区域 | 点清晰预览画面关闭；左侧模糊填充沿用原厂行为 |
| 设置与框架恢复 | 0.219、LSPosed、原相机作用域及身份配置已恢复 |

运行时原生云端目录可以追加项目，不把初次加载的项数当成固定上限。滑动手势应从列表内部开始；底部固定原图按钮仍拥有自己的触摸区域。

## 限制

- 复用的是移植相机 6.6 中的原厂分支；系统原厂 6.7 的资源有版本差异，未用手工尺寸去强行模拟，不声称逐像素一致。
- 上述保留验证针对关闭／重开效果面板。冷启动会重置滤镜，补丁未改写启动保留策略。
- 本轮未重新验证所有拍摄模式及最终成片处理，既有验证不视作本轮全部重测。
- Antigravity CLI 曾被用于只读源码复核尝试，但没有返回有效报告；本轮实现及设备验证由维护流程独立完成。
- 仓库中旧版展示图经过取景内容替换，不作为 0.10 滤镜面板的像素证据；本轮含私人取景内容的原始截图不上传。
